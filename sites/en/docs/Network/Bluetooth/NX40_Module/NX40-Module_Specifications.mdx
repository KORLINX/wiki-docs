# NX40 Module Specifications

This page separates **nRF52840 SoC specifications** from NX40 module design data. NX40-specific RF, current, and voltage measurements are not available. Values identified as SoC specifications come from the [Nordic nRF52840 Product Specification](https://docs.nordicsemi.com/r/bundle/ps_nrf52840/) and are not measured or guaranteed NX40 module values.

> **Note:** Use the released NX40 datasheet, schematic, BOM, controlled mechanical drawing, and qualification report for production design.

## Key Specifications

| Item | Specification | Status |
| --- | --- | --- |
| Main SoC | Nordic Semiconductor nRF52840-CKAA | Component identification |
| CPU | 64 MHz Arm Cortex-M4 with FPU | SoC capability |
| SoC memory | 1 MB Flash, 256 kB RAM | SoC capability |
| Additional Flash | 32 Mbit on `32` models; none on `00` models | Exact device/BOM pending approval |
| Radio | Bluetooth Low Energy PHYs and IEEE 802.15.4 at 250 kbps | Availability depends on software and qualification |
| TX setting | −20 to +8 dBm | nRF52840 reference range |
| USB | USB 2.0 full-speed device | Host implementation requires review |
| Interfaces | GPIO, ADC, UART/UARTE, SPI, QSPI, TWI/I²C, PWM, PDM, I²S, NFC-A, SWD | Pin assignment depends on firmware |
| Package | LGA surface-mount module | KORLINX design data |
| Size | 9.5 × 9.5 × 1.95 mm nominal | Tolerances pending controlled drawing |

## SoC Recommended Operating Conditions

| Parameter | Min. | Nom. | Max. | Unit | Condition |
| --- | ---: | ---: | ---: | --- | --- |
| VDD | 1.7 | 3.0 | 3.6 | V | nRF52840 SoC, normal-voltage mode |
| VDDH | 2.5 | 3.7 | 5.5 | V | nRF52840 SoC, high-voltage mode |
| VBUS | 4.35 | 5.0 | 5.5 | V | nRF52840 SoC USB supply; does not alone define NX40 power routing |
| Ambient temperature | −40 | 25 | +85 | °C | nRF52840 SoC range; NX40 module qualification not measured |

## SoC Absolute Maximum Ratings

| Parameter | Min. | Max. | Unit | Basis |
| --- | ---: | ---: | --- | --- |
| VDD | −0.3 | +3.9 | V | nRF52840 component limit |
| VDDH | −0.3 | +5.8 | V | nRF52840 component limit |
| VBUS | −0.3 | +5.8 | V | nRF52840 component limit |
| GPIO voltage, VDD ≤ 3.6 V | −0.3 | VDD + 0.3 | V | nRF52840 component limit |
| RF input | — | +10 | dBm | nRF52840 component limit |
| Storage temperature | −40 | +125 | °C | SoC limit; module qualification pending |

These nRF52840 limits are stress limits and do not describe normal operation. Module ESD and production limits remain subject to NX40 qualification.

## Nordic SoC RF and Current Specifications

These values describe the nRF52840 SoC under Nordic's stated conditions. They do not include NX40 module losses, additional Flash current, antenna performance, or customer-board effects. Current values below are typical SoC values at 3 V and 25°C; the radio rows identify the DC/DC conditions used.

| Item | Typical / range | Nordic condition |
| --- | --- | --- |
| BLE 1 Mbps sensitivity | −95 dBm | nRF52840 receiver specification |
| BLE coded 125 kbps sensitivity | −103 dBm | nRF52840 receiver specification |
| IEEE 802.15.4 sensitivity | −100 dBm | 250 kbps SoC receiver specification |
| TX current at +8 dBm | 14.8 mA | DC/DC, 3 V |
| RX current | 4.6 mA | BLE 1 Mbps, DC/DC, 3 V |
| System OFF current | 0.40 µA | 3 V, no RAM retention |

See Nordic's [nRF52840 radio electrical specification](https://docs.nordicsemi.com/r/bundle/ps_nrf52840/page/radio.html) and [current-consumption conditions](https://docs.nordicsemi.com/r/bundle/ps_nrf52840/page/chapters/current_consumption/doc/frontpage.html).

## NX40 Module Characterization

KORLINX has not completed detailed NX40 module-level RF, voltage, or current measurements. No numeric module-level performance values are published on this page. Validate the final hardware, firmware, power topology, antenna, and enclosure for the intended application.

## Software Capability Boundary

| Capability | Hardware basis | Evidence required for an NX40 product claim |
| --- | --- | --- |
| nRF Connect SDK / Zephyr | Supported by the underlying Nordic platform | Tested SDK version, board target, repository, and release notes |
| Bluetooth Low Energy | Supported radio PHY | Bluetooth qualification identifiers and tested controller/host stack |
| Thread / Zigbee | IEEE 802.15.4 radio capability | Qualified stack version and interoperability evidence |
| Matter over Thread | Software dependent | Matter SDK version, certification scope, and validated application |
| USB | Full-speed device hardware | Validated host design and firmware example |
| Additional Flash | `32` variants only | Confirmed JEDEC ID, driver, modes, frequency, and power management |
