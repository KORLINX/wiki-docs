# NX40 Module Overview

<img src="/img/bluetooth/nx40/series/NX40-Overview.png" alt="NX40 integrated and external antenna module variants" className="blog-first-image" />

The **KORLINX NX40 Series** is a compact 2.4 GHz multiprotocol wireless module based on the Nordic Semiconductor **nRF52840-CKAA**. It integrates the SoC, 32 MHz crystal, RF matching network, shielding, and an antenna connection in a 9.5 × 9.5 mm LGA package.

NX40i models include a ceramic chip antenna. NX40E models route RF to an on-module micro-coax connector. Models ending in `32` add 32 Mbit serial multi-I/O Flash; models ending in `00` omit this memory.

> **Technical review status:** The module routing, mechanical tolerances, module-level electrical characterization, antenna qualification, and production-process limits require approval against the released BOM, PCB, and qualification records before production use.

## Main Highlights

- 64 MHz Arm Cortex-M4 processor with floating-point unit
- 1 MB embedded Flash and 256 kB RAM in the nRF52840 SoC
- Bluetooth Low Energy 1 Mbps, 2 Mbps, and coded PHY support
- IEEE 802.15.4 radio capability at 250 kbps
- USB 2.0 full-speed device and common embedded interfaces
- Integrated-antenna and external-antenna options
- Optional 32 Mbit serial multi-I/O Flash
- 9.5 × 9.5 × 1.95 mm nominal LGA module envelope

Protocol availability depends on the released firmware, software stack, qualification, and regional configuration.
