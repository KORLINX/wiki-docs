# NX15 Dev Kit Hardware

<img
  src="/img/bluetooth/nx15/quick-start/NX15-dev-kit-front.png"
  alt="NX15 Dev Kit hardware overview front view"
  className="blog-first-image"
/>

The **NX15 Dev Kit** provides the board-level hardware required to evaluate and develop applications with the **KORLINX NX15 Series BLE module**.

This page focuses on the Dev Kit hardware: USB connection, debugging interface, onboard sensors, buttons, LEDs, expansion headers, battery support, and the J3/J4 header pin map.

:::note
This page describes the **NX15 Dev Kit board**.

For module-level information such as LGA pad layout, antenna design, electrical/RF specifications, tape and reel packing, and soldering conditions, refer to the NX15 Module pages.
:::

---

## Hardware Overview

The NX15 Dev Kit combines the NX15 Series BLE module with development-friendly hardware so that users can test firmware, sensors, user input/output, serial communication, and external signal access more easily.

| Block | Contents | Purpose |
| --- | --- | --- |
| Core Module | NX15 Series BLE module | Main wireless and processing module used on the Dev Kit |
| USB & Debugging | USB Type-C, FTDI FT234XD, SWD header, ESD/TVS protection | PC connection, serial communication, firmware programming, and debugging |
| LED & Switch | RGB LED, charge/power LEDs, reset button, user button | Firmware status indication and user input testing |
| Sensors | LSM6DS3TR-C 6-axis IMU, SHTC3 temperature/humidity sensor | Motion, orientation, temperature, and humidity example development |
| Headers | J3 and J4 headers | Selected signal access for prototyping and external connection |
| Battery Support | Li-Po connector, BQ25100 charger IC | Battery-oriented BLE prototype testing |

## Key Features

- **Development-ready board:** Provides the essential hardware needed to evaluate the NX15 Series BLE module.
- **USB Type-C connection:** Allows convenient PC connection for development and testing.
- **USB-to-UART interface:** Uses FTDI FT234XD for serial communication during development.
- **SWD debugging:** Provides SWD access for programming, debugging, and firmware validation.
- **Onboard sensors:** Includes LSM6DS3TR-C 6-axis IMU and SHTC3 temperature/humidity sensor for example applications.
- **User input and status output:** Provides reset/user buttons, RGB LED, charge LED, and power LED.
- **Expansion headers:** Exposes selected module signals through J3 and J4 headers for prototyping.
- **Battery-oriented prototyping:** Includes Li-Po connector and BQ25100 charger IC for battery-related test workflows.

## USB and Debugging

The NX15 Dev Kit includes USB and debugging hardware for firmware development, serial communication, and board bring-up.

| Hardware | Purpose |
| --- | --- |
| USB Type-C | Main PC connection during development |
| FTDI FT234XD | USB-to-UART communication interface |
| SWD header | Firmware programming and debugging interface |
| ESD / TVS protection | Protection for USB and external interface areas |

Use the USB Type-C connector for normal development connection. Use the SWD header when firmware programming, debugging, or recovery access is required.

The NX15 Dev Kit provides expansion headers and battery-related hardware for prototype development.

| Hardware | Purpose |
| --- | --- |

## Pin Map

<img
  src="/img/bluetooth/nx15/hardware/NX15_Pin_List.png"

  className="blog-first-image"

The NX15 Dev Kit exposes selected NX15 module signals through the J3 and J4 header areas. These headers can be used for prototyping, external sensor connection, GPIO testing, and firmware validation.

:::note
This pin map shows the **NX15 Dev Kit J3/J4 header signals**. Pin 1 is the square pad at the USB Type-C end of each header.

It is not the full NX15 module LGA pad map. For the full module pad map, refer to the NX15 Module Pin Map page.
:::

## Pin Usage Notes

| Item | Note |
| --- | --- |
| Header pin map | The J3/J4 tables describe selected Dev Kit header signals only |
| Module LGA pad map | The full NX15 module LGA pad map is documented separately in the NX15 Module Pin Map page |
| GPIO function | GPIO and peripheral functions depend on firmware configuration |
| NFC pins | NFC-related pins may require firmware configuration before use as GPIO |
| ADC pins | Analog input routing should be kept away from noisy or high-speed traces |
| Production design | Confirm the final Dev Kit schematic and NX15 module datasheet before production use |
