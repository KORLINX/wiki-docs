# NX15 Dev Kit Hardware

<img
  src="/img/bluetooth/nx15/quick-start/NX15-dev-kit-front.png"
  alt="NX15 Dev Kit hardware overview"
  className="blog-first-image"
/>

The **KORLINX NX15 Dev Kit** is a compact development board designed for evaluating, prototyping, and developing applications with the **NX15 Series BLE module**. Based on the Nordic **nRF54L15** platform, the NX15 Series integrates a multi-protocol 2.4 GHz radio, a **128 MHz Arm Cortex-M33 processor**, a **128 MHz RISC-V coprocessor**, up to **1.5 MB internal NVM and 256 KB RAM**, and optional external Flash depending on the model. The Dev Kit provides essential hardware for early development, including **USB Type-C**, **FTDI USB-to-UART**, **SWD debugging**, onboard **LSM6DS3TR-C 6-axis IMU**, **SHTC3 temperature/humidity sensor**, RGB LED, user/reset buttons, expansion headers, Li-Po connector, and battery charging support. It is ideal for BLE sensor demos, wearable prototypes, smart home devices, industrial monitoring nodes, and other compact wireless IoT applications.

## Hardware Overview

The NX15 Dev Kit includes USB connectivity, debugging access, user input, status output, onboard sensors, expansion headers, and battery-related hardware.

| Block | Contents |

| Sensors | LSM6DS3TR-C 6-axis IMU, SHTC3 temperature/humidity sensor |

## Features

- **Powerful Processing:** Built around the Nordic nRF54L15 platform with a 128 MHz Arm Cortex-M33 processor and a 128 MHz RISC-V coprocessor for advanced BLE and embedded IoT applications.
- **Bluetooth LE 5.4 Connectivity:** Supports Bluetooth LE 5.4 for wireless sensor nodes, BLE beacons, asset tracking, wearable devices, smart home devices, industrial monitoring, remote controls, and PC peripherals.
- **Multiprotocol 2.4 GHz Support:** Provides 802.15.4 capability for Thread and Zigbee applications, with Matter over Thread support depending on the selected software stack.
- **Compact NX15 Module Platform:** Uses the ultra-compact NX15 Series BLE module with a 9.5 × 9.5 × 1.95 mm LGA package, designed for space-constrained IoT products.
- **Rich Memory Resources:** Includes 1.5 MB internal NVM and 256 KB RAM, with optional external Flash depending on the NX15 module model.
- **On-board Sensor Support:** Includes an LSM6DS3TR-C 6-axis IMU and an SHTC3 temperature/humidity sensor for motion, orientation, and environmental sensing examples.
- **Development-ready Hardware:** Provides USB Type-C, FTDI FT234XD USB-to-UART, SWD debugging, RGB LED, charge/power LEDs, reset button, user button, J3/J5 headers, Li-Po connector, and BQ25100 charger IC.
- **Zephyr-based Development:** Compatible with the nRF Connect SDK and Zephyr RTOS development workflow.

## Pin Map

The NX15 Dev Kit exposes commonly used NX15 module signals through the J3 and J5 header areas. These pins can be used for prototyping, external sensor connection, GPIO testing, and firmware validation.

:::note
This pin map is based on the NX15 Dev Kit pin illustration and cross-checked with the NX15 external LGA pad description in the NX15 Datasheet. Always confirm the final header mapping with the official schematic before production use.
:::

### J5 Header

| Pin Order | Pin Label | Type | Description |
| --- | --- | --- | --- |
| 1 | GND | Ground | Common ground reference |
| 2 | P2.08 | GPIO / Trace | General-purpose I/O or trace-related alternate function |
| 3 | P1.03 / NFC2 | GPIO / NFC | GPIO or NFC2 antenna interface |
| 4 | P1.02 / NFC1 | GPIO / NFC | GPIO or NFC1 antenna interface |
| 5 | 3.3V | Power | 3.3 V output / board power rail reference |
| 6 | GND | Ground | Common ground reference |
| 7 | VBUS | Power | USB bus voltage input |

### J3 Header

| 3 | P1.11 / AIN4 | GPIO / ADC | GPIO or analog input channel AIN4 |
| 4 | P1.07 / AIN3 | GPIO / ADC | GPIO or analog input channel AIN3 |
| 5 | P1.06 / AIN2 | GPIO / ADC | GPIO or analog input channel AIN2 |
| 6 | P1.05 / AIN1 | GPIO / ADC | GPIO or analog input channel AIN1 |
