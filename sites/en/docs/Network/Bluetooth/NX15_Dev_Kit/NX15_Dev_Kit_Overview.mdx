# NX15 Dev Kit Overview

<img
  src="/img/bluetooth/nx15/quick-start/NX15-dev-kit-front.png"
  alt="NX15 Dev Kit front view"
  className="blog-first-image"
/>

The **KORLINX NX15 Dev Kit** is a compact development board for evaluating, prototyping, and developing applications with the **NX15 Series BLE module**.

It is designed to help developers quickly test BLE applications, validate onboard sensors, check user input/output behavior, and begin firmware development before moving to a custom product design.

:::note
This page describes the **NX15 Dev Kit**.

For module-level information such as model lineup, LGA pad layout, antenna design, electrical specifications, and soldering guidance, refer to the **NX15 Module** pages.
:::

---

## What Is the NX15 Dev Kit?

The NX15 Dev Kit is an evaluation and development board built around the NX15 Series BLE module.

It provides the hardware needed for early development, including USB connection, serial communication, debugging access, onboard sensors, buttons, LEDs, expansion headers, and battery-related hardware.

The board is intended for development and validation. It is not a replacement for the NX15 module datasheet or the final custom PCB design guide.

---

## What You Can Do with the NX15 Dev Kit

| Task | Description |
| --- | --- |
| BLE application testing | Test BLE advertising, connection, and data transfer behavior |
| Sensor prototyping | Build examples using onboard motion and temperature/humidity sensors |
| Firmware validation | Check firmware behavior using buttons, LEDs, serial output, and debug access |
| Header signal testing | Access selected module signals through the J3 and J5 headers |
| Battery-oriented testing | Prototype BLE workflows with Li-Po battery and charging-related hardware |
| Early product evaluation | Validate application ideas before designing a custom PCB |

---

## Main Hardware Capabilities

| Area | Description |
| --- | --- |
| USB connection | USB Type-C connection for development and PC interface |
| USB-to-UART | FTDI FT234XD USB-to-UART interface |
| Debugging | SWD header for firmware programming and debugging |
| User interface | Reset button, user button, RGB LED, charge LED, and power LED |
| Sensors | LSM6DS3TR-C 6-axis IMU and SHTC3 temperature/humidity sensor |
| Expansion | J3 and J5 headers for selected signal access |
| Battery support | Li-Po connector and BQ25100 charger IC |
