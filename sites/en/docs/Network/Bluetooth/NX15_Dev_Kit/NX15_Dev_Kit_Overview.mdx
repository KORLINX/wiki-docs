# NX15 Dev Kit Overview

<img
  src="/img/bluetooth/nx15/quick-start/NX15-dev-kit-front.png"
  alt="NX15 Dev Kit front view"
  className="blog-first-image"
/>

The **NX15 Dev Kit** is a compact development board for evaluating and prototyping applications with the **KORLINX NX15 Series BLE module**.

It helps developers quickly start BLE application testing, onboard sensor validation, user input/output testing, and early firmware development before moving to a custom product design.

---

## What You Can Do with the NX15 Dev Kit

| Task | Description |
| --- | --- |
| BLE application testing | Test BLE advertising, connection, and data transfer behavior |
| Sensor prototyping | Build examples using onboard motion and environmental sensors |
| Firmware validation | Check firmware behavior using buttons, LEDs, serial output, and debugging access |
| Battery-oriented testing | Prototype BLE workflows with battery-related hardware |
| Early product evaluation | Validate application ideas before custom PCB development |

## When to Use This Dev Kit

The NX15 Dev Kit is suitable for:

| Use Case | Description |
| --- | --- |
| BLE sensor demo | Test wireless sensor data examples |
| Wearable prototype | Evaluate compact BLE and sensor-based workflows |
| Smart home / BAS prototype | Test BLE control or monitoring functions |
| Industrial monitoring prototype | Validate wireless monitoring concepts |
| Firmware bring-up | Test basic firmware, GPIO, sensor, LED, and debug behavior |
