# NX15 Module Overview

<img
  src="/img/bluetooth/nx15/module-integration/NX15-module-front.png"
  alt="KORLINX NX15 Series BLE module front view"
  className="blog-first-image"
/>

The **KORLINX NX15 Series** is an ultra-compact **Bluetooth Low Energy 5.4 module** designed for compact wireless IoT products.

Based on the Nordic **nRF54L15** platform, the NX15 Series integrates a multi-protocol 2.4 GHz radio, embedded processing, memory resources, security features, and antenna options in a small LGA module package.

NX15 is intended for applications such as BLE sensor nodes, beacons, asset tracking, wearable devices, smart home devices, building automation systems, industrial monitoring nodes, remote controls, and PC peripherals.

---

## What Is NX15?

NX15 is a module-level product intended to be integrated into a custom device or host PCB.

It provides the wireless and processing foundation for Bluetooth Low Energy and 2.4 GHz IoT applications. Developers can use the NX15 module to build compact connected products while reducing the need to design the RF section from the beginning.

:::note
This page describes the **NX15 module**.

For the development board used for evaluation, prototyping, and firmware testing, see the NX15 Dev Kit pages.
:::

---

## Main Highlights

- **Compact BLE module:** Designed for space-constrained IoT products.
- **nRF54L15-based platform:** Built around the Nordic nRF54L15 SoC.
- **Bluetooth LE 5.4:** Supports BLE applications such as sensors, beacons, and connected devices.
- **2.4 GHz multiprotocol support:** Supports 802.15.4-based application planning such as Thread and Zigbee.
- **Matter over Thread ready:** Matter over Thread support depends on the selected software stack.
- **Flexible model options:** Available with chip antenna or u.FL external antenna options.
- **Optional external Flash:** Available on selected models depending on memory requirements.
- **LGA package:** Suitable for compact surface-mount product designs.

## Model Options

<img
  src="/img/bluetooth/nx15/module-integration/NX15-model-lineup.png"
  alt="NX15i and NX15E module lineup"
  className="blog-first-image"
/>

The NX15 Series includes chip-antenna and u.FL external-antenna variants, with or without 32 Mbit SPI Flash.

| Model | Antenna | Flash | GPIO | Primary Use |
| --- | --- | --- | --- | --- |
| NX15i32 | Chip antenna | 32 Mbit SPI Flash | 25 | Compact form factor with external Flash |
| NX15E32 | u.FL connector | 32 Mbit SPI Flash | 25 | External antenna with maximum RF performance |
| NX15i00 | Chip antenna | None | 25 | Compact IoT node with full GPIO access |
| NX15E00 | u.FL connector | None | 25 | External antenna with full GPIO access |
