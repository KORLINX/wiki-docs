# NX40 Dev Kit Overview

<img
  src="/img/bluetooth/nx40/quick-start/NX40_DK_Variants.png"
  alt="NX40 Dev Kit variants"
  className="blog-first-image"
/>

The **NX40 Dev Kit** is a compact development board for evaluating and prototyping applications with the **KORLINX NX40 Series** module.

It is designed to help developers quickly start BLE application testing before moving to a custom product design.

The board provides the basic development environment for testing wireless behavior, onboard sensor examples, user input, status output, debugging access, and battery-oriented prototype workflows.

---

## What You Can Do with the NX40 Dev Kit

| Task | Description |
| --- | --- |
| BLE application testing | Test BLE advertising, connection, and data transfer behavior |
| Sensor prototype | Build simple examples using onboard motion and environmental sensors |
| Firmware bring-up | Validate firmware behavior using buttons, LEDs, serial output, and debugging access |
| Battery-oriented testing | Prototype low-power BLE workflows with battery-related hardware |
| Early product validation | Test core application ideas before designing a custom PCB |
