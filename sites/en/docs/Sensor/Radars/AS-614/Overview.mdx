# AS-614 60 GHz Radar Module Overview

AS-614 is a compact 60 GHz multi-channel FMCW radar module for indoor position, occupancy, and closest-person vital-sign sensing. It integrates a 1 TX / 4 RX antenna system and on-board processing on a 32 × 30 mm board and provides GPIO, TTL UART, optional connector hardware, USB-C power input, and an indicator LED.

:::note
Official reference
This page follows the AS_614 with AI User Manual, Ver.5.00 Jan.2025. The manual writes the model as `AS_614`; this Wiki uses the customer-facing name `AS-614`.
:::

## Pin map

With USB-C at the top and P2 at the bottom, P1 is the eight-pin header on the left. P2 is the six-pin board connector.

:::caution
Pin 1 orientation requires confirmation
Manual v5.00 page 2 places P1 Pin 1 at the bottom of the header, near the square pad. The supplied Pin List artwork numbers it from the top. Confirm the production revision before applying power; do not combine the two orientations. The signal table follows the manual.
:::

![AS-614 P1 header and P2 connector pin list](/img/Sensor/Radars/AS-614/AS-614_Pin_List.png)

*P1 and P2 signal assignments. See the orientation note above before wiring.*

| Pin | Signal | P1 header | P2 connector |
| --- | --- | --- | --- |
| 1 | VCC | 3.3-7.0 V power input | 3.3-7.0 V power input |
| 2 | GND | Power ground | Power ground |
| 3 | GPIO | Input/output; output by default | Input/output; output by default |
| 4 | NRST | Open or High: normal; Low: reset | Open or High: normal; Low: reset |
| 5 | UART TX | Module transmit | Module transmit |
| 6 | UART RX | Module receive | Module receive |
| 7 | N.C. | Not used | Not available on six-pin P2 |
| 8 | N.C. | Not used | Not available on six-pin P2 |

- `P1`: eight-pin 2.54 mm header
- `P2`: `12505WR-06`; mating connector `12505HS-06`
- `J1`: USB-C connector used solely for power supply

The manual states that GPIO is an output by default: High when a target is detected and Low when no target is detected. It also says GPIO can be set as an input, but it does not provide the configuration command or a complete packet definition for that input mode.

:::note
Electrical details not specified
The manual does not define GPIO current limits, pull states, NRST timing, UART absolute maximum ratings, ESD limits, connector current ratings, or USB-C CC/power-path implementation.
:::

| 5 | Wall/side | Closest-person heart rate, breathing rate, waveform, and optional position | Default |
| 6 | Wall | Position slots plus closest-person vital signs | Default |
| 10 | Application-specific | Raw real/imaginary antenna data | Additional license |
| 11 | Wall/side | Advanced vital signs with RMSSD and SDNN | Additional license |

## Coordinate system

For wall installation:

- X: left (-), right (+)
- Y: down (-), up (+)
- Z: forward (+)

For ceiling installation:

- X: left (-), right (+)
- Y: height below the radar (-)
- Z: backward (-), forward (+)

The manual states that X-axis performance is relatively better than Y- or Z-axis performance. Coordinate signs are relative to the radar orientation.

![AS-614 wall and ceiling coordinate orientation](/img/Sensor/Radars/AS-614/as614-coordinate-system-1.png)

*Wall and ceiling coordinate views. Forward wall detection uses +Z; axis signs depend on the installed radar orientation and viewing direction. See [Position Detection](./Position_Detection#tune-the-region-of-interest) for distance and angle limits.*

## Detection-area controls

AS-614 uses `xmin`, `xmax`, `ymin`, `ymax`, `zmin`, and `zmax` in millimeters. Angle limits use positive values from 0° to 180°:

- `alrmin` / `alrmax`: left-to-right limits
- `adumin` / `adumax`: down-to-up limits

The manual says angle filtering is less precise than distance filtering. Use coordinate bounds for primary region control and validate the final boundary with real targets.

AS-614 does not document the `rotate`, `walltilt`, or exclusion-zone commands used by some other radar models. Do not transfer those commands into an AS-614 integration.

## Ordering structure

```text
AS_614_P/C/U
```

| Code | Meaning in the manual |
| --- | --- |
| `P` | 2.54 mm pin header installed |
| `C` | Board connector installed |
| `U` | USB-C connector installed |

Documented examples: `AS_614_U`, `AS_614_PU`, and `AS_614_CU`.

The order-information table contains a stray `AS_611` label. The heading, format, and examples identify the intended product as AS-614; confirm the final purchasable SKU list with KORLINX before publication.

## Operating limitations

- Position and occupancy modes respond to moving reflectors and cannot inherently distinguish a person from a pet, fan, curtain, cable, or other moving object.
- Stationary-person detection requires enough micro-motion and becomes harder at longer distances.
- Static-object detection provides Z distance only and may continuously report unwanted environmental reflectors.
- Multiple nearby people can merge into one target; a person directly behind another target can be hidden.
- Metallic or densely furnished environments can create multipath, virtual targets, or missed targets.
- Occupancy output is an approximation and can differ from the real count by 1-3 people. It is not intended for exact people counting.
- Vital-sign output is associated with the closest detected person and can be disrupted by closer motion or objects between the radar and the subject.
- The final detection range must be verified in the actual enclosure and installation environment.

:::danger
Not a medical or life-safety claim
The supplied manual does not provide medical-device certification, clinical validation, or regulatory conformity evidence. Do not use AS-614 output alone for diagnosis, treatment, emergency response, fall protection, pressure-ulcer prevention, or other safety-critical decisions.
:::

:::warning
Pacemakers and implantable devices
The manual warns not to use the device within 20 cm of a pacemaker or other implantable medical device and instructs users to consult the physician or device manufacturer first.
:::
