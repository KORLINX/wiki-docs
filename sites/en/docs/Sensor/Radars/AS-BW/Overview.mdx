# AS-BW Overview

The **AS-BW** is a Bluetooth and Wi-Fi communication module, not a radar. It connects to a radar module through UART and forwards the radar stream over 2.4 GHz Wi-Fi. It provides radar interworking and IoT bypass; radar analysis remains on the radar module.

## Documented limitations

The AS-BW user manual incorrectly lists the model name as `AS_614` in its specification table. This is a documentation error; the manual describes AS-BW. A source-document correction is pending.

AS-BW and its viewer application were under active stabilization during 2026. Confirm the installed firmware and viewer versions before investigating a field problem, because a corrected build may already exist.
