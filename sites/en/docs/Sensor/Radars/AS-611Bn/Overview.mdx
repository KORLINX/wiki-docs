# AS-611Bn 60 GHz Radar Module Overview

AS-611Bn is a compact 60 GHz pulsed radar module with an integrated antenna and signal processing. The supplied manual describes distance detection and single-person vital-sign detection, with sensor data available over UART or Bluetooth Low Energy (BLE).

:::note Documentation scope
This guide follows the supplied user manual marked **Ver.4.0 Jun.2026**. Check the installed model and firmware before applying commands. The manual lists D/V function options and a mode-selection command, but does not establish whether every commercial unit supports both functions.
:::

## Sensing functions

| Function | Documented output | Configurable range | Default range |
| --- | --- | --- | --- |
| Distance (`D`) | Distance and reflected strength for stationary or moving objects; up to 10 objects | 0.1–20 m | 0.25–3.0 m |
| Vital sign (`V`) | One person's heart rate, breathing rate, heart-beat pulse, respiration waveform, distance, and optional HRV | 0.15–2.5 m | 0.25–1.5 m |

The manual separately states human detection up to **4 m** in distance mode. The **20 m** value is a configuration limit, not a guarantee for every target or installation. Target properties, nearby reflectors, mounting, and settings affect results.

Vital-sign sensing is documented for **one human subject**. Front-facing chest placement and remaining steady for more than 20 seconds provide the best documented conditions. This is not a guaranteed time to a valid result. No product-specific accuracy percentage is presented here because the supplied manual does not define the test method or reference instrument.

### Signals listed for J1 and J2

Confirm connector orientation and pin numbering against the actual board revision before wiring.

| Pin | Signal | Documented purpose |
| ---: | --- | --- |
| 1 | VCC | 3.3–7.0 V power input |
| 2 | GND | Ground |
| 3 | GPIO | Input/output; behavior unspecified |
| 4 | NRST | Open or high: normal operation; low: reset |
| 5 | UART TX1 | Module transmits to host RX |
| 6 | UART RX1 | Module receives from host TX |

The manual additionally labels J1 pins 7/8 as UART TX2/RX2. Their availability and function on a specific AS-611Bn revision need confirmation. They are not extra positions on the six-position J2 connector.

:::warning UART voltage
UART uses 3.3 V logic. The supply range does not imply that signal pins tolerate 7 V. Use a compatible UART adapter and common ground; do not connect directly to RS-232.
:::

## Ordering and device identity

The manual's order-code pattern is `AS_611(Bn)_D/V_P/C/U`:

| Code | Meaning in the manual |
| --- | --- |
| `AS_611` | Base model |
| `AS_611Bn` | BLE-enabled model |
| `D` / `V` | Distance / vital-sign function option |
| `P` | Pin header installed |
| `C` | Board connector installed |
| `U` | USB-C power connector installed |

Confirm the complete orderable SKU and supported function with the supplier. AS-611Bn is the display name used here; literal order codes, BLE names, and protocol strings retain their documented spelling. The documented BLE advertising name is `AS_611B`, and the boot string is `#AS_611B_4.0!`.

## Operating limits

- Vital-sign sensing covers one person. Additional people, obstructions, nearby metal, and moving reflectors can interfere.
- Small movements and conversation can reduce vital-sign accuracy.
- Distance detection can include unwanted reflections from surrounding objects.
- The manual states that the indicator LED flashes when data is output; this alone does not confirm valid measurements.
- The supplied manual does not establish medical-device certification or diagnostic performance.
