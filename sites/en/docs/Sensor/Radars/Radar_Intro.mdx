# Radar Sensor Overview

The AnySensing product family includes three 60 GHz radar modules for distance, vital-sign, presence, posture, and fall-detection applications. The family also includes the AS-BW communication module, which connects a radar module to a Wi-Fi network.

## Choose a module

| Model | Class | Role |
| --- | --- | --- |
| [AS-611Bn](./AS-611Bn/Overview) | 60 GHz pulsed radar module, 1 TX / 1 RX | Single-target distance sensing or single-person vital-sign sensing. Designed for OEM integration and equipped with onboard Bluetooth Low Energy (BLE). |
| [AS-614](./AS-614/Overview) | 60 GHz frequency-modulated continuous-wave (FMCW) AI radar module, 1 TX / 4 RX | The incumbent bed sensor in deployed InCare24 hospital systems. It remains in production while AS-613 progressively replaces it in new installations. |
| [AS-613](./AS-613_Radar/Overview) | 60 GHz FMCW AI radar module, 1 TX / 3 RX | The current flagship model for new installations and conversions. Supports multiple targets—up to five people—fall detection, and posture detection. |
| [AS-BW](./AS-BW/Overview) | Bluetooth / Wi-Fi communication module | Not a radar. Carries a radar module's UART stream over 2.4 GHz Wi-Fi as the communication-module half of an InCare24 ceiling unit. |

## Understand the model numbers

The radar model number describes its frequency band and antenna configuration:

```text
AS(ABC)

AS = AnySensing
A  = frequency band (6 = 60 GHz)
B  = number of TX antennas
C  = number of RX antennas
suffix B = BLE-equipped model
```

| Model | Meaning |
| --- | --- |
| AS-611 | 60 GHz, 1 TX, 1 RX |
| AS-611B / AS-611Bn | BLE-equipped AS-611 |
| AS-613 | 60 GHz, 1 TX, 3 RX |
| AS-614 | 60 GHz, 1 TX, 4 RX |
| AS-622 | 60 GHz, 2 TX, 2 RX; outside the scope of this documentation |

AS-BW does not follow this naming rule because it is a communication module rather than a radar. Current documents are standardizing `AS-611Bn` as `AS-611B`. **[VERIFY]**
