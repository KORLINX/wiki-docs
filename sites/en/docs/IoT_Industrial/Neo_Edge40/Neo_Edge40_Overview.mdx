# NEO-Edge40 Overview

The **KORLINX NEO-Edge40** connects wireless sensors, industrial equipment, and field I/O to local or remote systems. It combines data collection, edge processing, communications, and output control on one platform.

> **Development status:** This documentation describes the NEO-Edge40 Rev. 1.0 platform. Planned features and values that still require hardware or certification review are identified on the [Hardware](./Neo_Edge40_Hardware) page. Confirm final specifications before designing a production system.

## At a glance

| Need | NEO-Edge40 capability |
| --- | --- |
| Collect wireless sensor data | BLE and Zigbee through the KORLINX NX40 module |
| Connect industrial equipment | Ethernet, RS-485, and CAN |
| Read field signals | Analog and opto-isolated digital inputs |
| Control field equipment | Relay, DC, analog, and GPIO outputs |
| Connect a remote site | Optional LTE-M / NB-IoT expansion |
| Process data locally | Filtering, conversion, status evaluation, alarms, protocol conversion, and control logic |
| Check status on site | Planned front LCD for values, communications, alarms, and output states |

## How it works

NEO-Edge40 sits between field devices and an upper-level system such as a PC, local server, cloud platform, or industrial controller.

1. **Collect:** Receive data from BLE or Zigbee devices, wired equipment, and analog or digital inputs.
2. **Process:** Filter and convert values, evaluate status, apply alarm rules, or run local control logic.
3. **Connect or control:** Send data upstream through Ethernet, cellular, RS-485, or CAN, and operate field outputs when required.

```text
Sensors and field equipment
            ↓
    NEO-Edge40 processing
        ↙             ↘
Upper-level system   Field outputs
```

## Choose a connection

| Connection | Use it for |
| --- | --- |
| BLE / Zigbee | Wireless sensors, beacons, and nodes |
| Ethernet | A LAN, local server, PC, or gateway uplink |
| RS-485 | Industrial instruments and field equipment |
| CAN | CAN-based equipment or controller integration |
| LTE-M / NB-IoT | Remote sites without a wired network; requires the optional cellular module |
| Analog / digital inputs | Current, voltage, and contact signals from field sensors |
| Relay / DC / analog outputs | Switching or controlling connected equipment |

## Typical applications

- BLE or Zigbee sensor hubs
- Factory equipment monitoring and local control
- Smart agriculture and environmental monitoring
- Building and energy-management systems
- Remote telemetry over LTE-M or NB-IoT
- OEM industrial controllers
